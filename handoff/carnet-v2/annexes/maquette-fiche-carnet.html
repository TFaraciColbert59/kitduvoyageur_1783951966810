Fiche carnet

Le téléphone reproduit /compte : les cinq tiroirs sont les cinq slots, les dix-huit sous-tiroirs sont les lentilles. Contenu d'exemple, rien n'est enregistré.

Jour affiché
Ouvrir un tiroir
États
Thème de la page
Gestes
  • ← → ou glisser la carte du haut : changer de jour
  • Capsule J en bas à droite : choisir le jour
  • Appui long sur une tuile (460 ms) : aperçu, puis Lire, Voir sur la carte, Épingler
  • Appui long sur une pastille « À la une » (500 ms) : modifier
  • Toucher une photo ou un moment : post (j’aime, commentaires, partage ; glisser à gauche = commentaires, à droite = partage, vers le bas = fermer)
  • Toucher la photo du carnet : stories des voyageurs (barres 5 s, maintien ou saisie = pause, tape 30 / 70 % = précédent / suivant, glisser vers le bas = fermer, répondre = message privé)
  • Tiroir : glisser la poignée vers le bas, ou Échap
  • Lentilles : glisser horizontalement le contenu (seuil 48 px)
  • Poignée de la carte : agrandir ou réduire. Toucher une trace : changer de jour
  • Profil d'altitude : glisser le curseur (haptique à chaque point)
  • Ctrl/⌘ + Z : annuler la dernière confirmation
