## 6. Risques
- Données de prod : base réelle (projet icxyvwzfjbflcbqukpfz) avec carnets, likes, commentaires, moments, kit, sorties, stories ; tout changement = migration additive et idempotente (add column if not exists, pas d'UPDATE destructeur, comme 20260911530000) + `.down.sql` ; ne pas renommer/supprimer carnet_*, hike_session_*, groupe_etapes/hebergements (encore lus par getCarnetDetail alors que la migration de dépréciation est différée) ; ne pas modifier le DEFAULT 'private' de carnets.visibility ; compteurs likes_count/comments_count tenus par triggers (ne pas les mettre à jour à la main).
