## 3. Auth Routes Missing `robots: noindex` — High Priority

**SEO Impact:** High
**Affected Files:** `src/app/connexion/page.tsx` (line 1), `src/app/inscription/page.tsx` (line 1)
**Status:** Missing

Auth routes (login, signup, password reset) should never be indexed by search engines. They serve no SEO value and dilute crawl budget. These pages currently have no metadata export, meaning they inherit the root layout's `index: true` setting.

**Why it matters:**
- Prevents wasted crawl budget on non-public pages
- Avoids duplicate content issues
- Protects user privacy (login pages in search results)
- Improves site structure clarity for search engines

**Evidence:** `src/app/connexion/page.tsx` (line 1) — File is marked `'use client'` with no `export const metadata` statement. Same for `src/app/inscription/page.tsx`.

**Current Implementation:**
```typescript
// ❌ No metadata export
'use client';
import React, { useState, Suspense } from 'react';
// ... rest of component
```

**Recommended Fix:**
Add metadata export to both files with `robots: { index: false, follow: true }`.
