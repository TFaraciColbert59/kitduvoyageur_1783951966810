# Pictos ajoutés (assets/icons/extra/)

Les 160 pictos de l'app (`assets/icons/sf/`) sont des glyphes **Phosphor Icons, graisse « bold »** (viewBox 256, licence MIT, voir `../sf/LICENSE.txt`). Les ajouts viennent de la même bibliothèque et de la même graisse : paquet npm `@phosphor-icons/core` 2.1.1 (MIT, `LICENSE-phosphor.txt`). Fichiers recoloriés en `#000` pour servir de masque (couleur réelle = `currentColor` via `mask-image`).
