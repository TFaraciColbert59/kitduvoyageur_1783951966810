## Intégration

Chaque fichier SVG est autonome et peut être utilisé comme image dans Next.js ou une WebView.

```tsx
<img src="/icons/lkdv/monde.svg" width={24} height={24} alt="Monde" />
```

Ne pas recolorer par filtres CSS ni ajouter de dégradés au trait; modifier `COLOR` dans le générateur pour changer la teinte de tout le pack.
