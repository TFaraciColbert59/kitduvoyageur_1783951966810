# C01 · K3.04 / K3.05 — couches carte et terrain

Date : 2026-11-13. Périmètre : Explorer v2, fiche **K3.04** (surcouches
surface, pente, hors-route) et fiche **K3.05** (fonds topographiques nationaux
officiels). Aucun test, build, lint ni `tsc` n'a été exécuté : la mission les
reporte explicitement. Aucune migration, aucun commit, aucune mise en
production.

## 1. Fiches lues

Les fiches détaillées ne sont pas versionnées dans ce dépôt ; elles ont été
lues dans le bundle de mission (`fiches/Komoot/`).

- `fiches/Komoot/K3.04.md` — « Couches sportives avancées : surface, pente et
  hors-route », état initial **Partiel**, chantier **C01**, dépendance **P01**.
- `fiches/Komoot/K3.05.md` — « Cartes topographiques nationales officielles »,
  état initial **Non repéré**, condition **Accès, licence ou arbitrage à
  valider**, exigence externe **TOPO_NATIONALE**.

Les deux fiches demandent un drawer/sous-drawer ouvert sur action explicite,
avec retour au drawer parent et conservation du contexte. Le tiroir existant
`Calques` (`SheetContent.tsx`) est réutilisé : aucune nouvelle route, aucun
nouvel écran.

## 3. Livré

### K3.04 · pente réelle de l’itinéraire

- `map/slope.ts` : seuils `04_CARTE.md §2` (< 8 %, 8–15 %, 15–25 %, > 25 %),
  transformation du profil en arrêts `line-gradient`, synthèse D+/D−/altitudes.
  Une altitude absente ne devient jamais une pente à 0 : elle reçoit la couleur
  neutre et coupe le calcul local.
- `data/useRouteSlope.ts` : appelle le service DEM existant uniquement quand la
  couche est demandée et qu’un itinéraire est prêt ; annule la requête au
  masquage, ignore une réponse tardive.
- `map/MapStage.tsx` : source `xp-slope` créée avec `lineMetrics: true`, couche
  `xp-slope-line` sous la trace active, dégradé mis à jour sans recréer la
  carte. La couche est masquée par défaut.
- `sheet/SheetContent.tsx` : ligne « Pente de l’itinéraire » avec état réel
  (sélection requise, calcul, prêt, relief indisponible) et D+/altitudes issus
  du profil. Le réglage existant `layerVisibility.slope` est réutilisé.

### K3.04 · surface et hors-route

- `app/api/explorer/v2/terrain/coverage/route.ts` : vérifie en lecture seule la
  présence de `trail_segments` et `hiking_routes` (aucune géométrie renvoyée,
  aucune migration).
- `data/hooks.ts` : `useTerrainCoverage()` alimente le tiroir.
- Le tiroir affiche « Surface du sol » avec l’état réel : « aucun segment
  importé » aujourd’hui, « segments disponibles mais couche non activée » si la
  table est remplie plus tard. Aucun faux calque n’est proposé.
- « Hors-route » expose l’état du dispositif existant (seuil, retour, écart
  courant) ; ce n’est pas un calque de données statique.
- Note explicite : marche, vélo de route, gravel et VTT partagent ces couches ;
  aucune surface par sport n’est affichée sans données importées.

### K3.05 · fonds nationaux officiels

- `map/nationalTopo.ts` : registre typé, séparé du sélecteur Relief / Satellite
  / Plan. Chaque source porte pays, fournisseur, licence, attribution,
  couverture et statut `verified` / `unverified`.
- Seule la France est déclarée (`fr-ign-plan-v2`, Plan IGN v2, Etalab 2.0),
  avec le statut **`unverified`** : elle est visible comme information
  (« À confirmer »), jamais chargée.
- `MapStage` sait déjà afficher une source `verified` (source raster dédiée,
  sous les étiquettes) ; le jour où l’accès est confirmé, il suffit de passer
  son statut à `verified`, sans changer le contrat de la carte.
- Le tiroir affiche un état vide pour les pays sans source déclarée, et un
  avertissement quand une source reste à confirmer.

## 4. Dépendances

| Dépendance | Usage | Risque / conflit |
|---|---|---|
| `P01` (confidentialité et publication) | Aucune donnée personnelle dans ces couches ; le hors-route reste local à la séance | Aucun nouveau chemin d’accès ; ne pas exposer la position exacte dans un partage. |
| `get_route_geojson` / `POST /api/explorer/v2/profile` | Pente réelle | Route lourde sur un itinéraire très long : plafond 1 500 points côté client, 6 000 côté API. |
| DEM AWS Terrarium | Altitudes et pente | Tuile indisponible = trou DEM, pas une valeur inventée ; la couche peut être vide. |
| `trail_segments` (OSM, ODbL) | Surface | Table vide aujourd’hui ; aucune couche dessinée. |
| `hiking_routes` (OSM, ODbL) | Tracés | Seuls des itinéraires de randonnée sont présents ; aucune donnée route/gravel/VTT dédiée. |
| `TOPO_NATIONALE` (IGN) | Fond national | Accès, couverture et charge non confirmés ; source non activée. |
| MapLibre 6 | `line-gradient` | Nécessite `lineMetrics: true` sur la source ; si le worker/style l’ignore, la couche se masque au lieu d’afficher un faux dégradé. |
| OpenFreeMap / Esri | Fonds existants | Inchangés ; l’attribution IGN devra être ajoutée aux mentions légales lors de l’activation. |

## 5. Conflits possibles et décisions

1. **`trail_segments` vide vs promesse « surface »** — décision : ne pas
   dessiner, afficher l’état réel. Aucune migration ni import dans cette
   tranche ; l’import OSM reste une dépendance externe.
2. **Pas de surfaces par sport** — décision : ne pas déduire une surface depuis
   `network` ou depuis le sport. La note du tiroir le dit ; les quatre pratiques
   partagent les mêmes couches tant que la base ne porte pas l’information.
3. **Pente stockée vs calculée** — décision : calcul à la demande depuis le DEM
   existant, car aucune colonne de pente n’existe et une migration est exclue.
   Le résultat est explicitement « AWS Terrain Tiles », pas une donnée stockée.
   Une géométrie `MultiLineString` est concaténée en une trace continue : un
   itinéraire réellement discontinu peut fausser la pente au raccord ; c’est
   une limite connue, aucune valeur n’est inventée pour la combler.
4. **IGN vs disponibilité** — décision : registre + statut `unverified`, aucune
   tuile chargée. Le code d’affichage existe pour une source `verified`, mais
   aucune disponibilité n’est affirmée.
5. **Tiroir Calques** — réutilisation de `LayersTab` et des lignes `XpRow` ;
   ajout d’un état `disabled` (informatif) pour ne pas fabriquer de bouton
   actif sans donnée.
6. **Fond national et cache hors ligne** — non traité : `offline/zone.ts`
   télécharge le fond vectoriel et le DEM, pas une source nationale. À ajouter
   avec l’activation IGN, sinon la zone hors ligne ne contiendrait pas le fond
   affiché.
7. **Attribution** — le fond national n’est pas affiché ; la mention
   « IGN — 2024 » devra être ajoutée à `mentions-legales` en même temps que
   l’activation, pas avant.
