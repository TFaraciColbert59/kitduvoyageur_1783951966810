# Compte iOS 27 v19 — feuille ancrée, profil compact, sorties fusionnées

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Les drawers du Compte deviennent une vraie feuille translucide (contenu de la card visible sous le verre) qui jaillit du bord bas de la card, se pilote au doigt, et gère tout en interne : profil compact sur 2 lignes, sorties fusionnées image + verre, compte à 5 onglets avec édition et partage sans quitter la feuille.

**Architecture:** Un bloc CSS `v19` en fin de `COMPTE_V8_APPLE_HIG_CSS` déplace les bornes de la card sur `.sw-wrap`, rend `.sheet` transparent (un seul voile Stone translucide, sans fond opaque ni double couche blanche), supprime le chrome d'en-tête et compacte profil/sorties. Le runtime passe d'un `setDet('closed')` instantané à une machine à états `open → dragging → closing → closed`, avec animation inverse et suivi du doigt. Les sélecteurs reçoivent une lentille pressable partagée ; le drawer Compte expose 5 cellules `.segc` et rend l'édition/le partage dans son propre corps.

**Tech Stack:** Next.js 15, React 19, CSS-in-string (`COMPTE_V8_APPLE_HIG_CSS`), runtime DOM `compte-liquid-glass-v8-runtime.js`, Vitest, Playwright.

**Spec:** Brief utilisateur du 2026-10-20 (cette conversation), synthèse et décisions en §1.

## Global Constraints

- **Invariant absolu** : zéro modification dans `src/app/compas/**` et `src/features/compas/**`.
- **Aucune couleur littérale nouvelle** : réutiliser `#17402C`, `#56665D`, `#3F4F46`, `#F5F2EC` (Stone documenté) et les tokens `--bar-glass-*`, `--bar-thumb-*`. La feuille ne peint plus de Stone opaque.
- **Aucune navigation depuis les sélecteurs internes** : pas de `window.location`, pas de `notifyHostAction('navtab')`, pas de `openSheet` déclenché par un onglet interne du drawer Compte. Les liens existants vers un profil tiers restent hors périmètre. Tout le reste est rendu localement et synchroniquement.
- **La card `#card.cs` reste la référence de matière** (blur, saturation, ombre), mais la feuille n'empile pas son gradient `.486/.384` : elle utilise un **seul** voile Stone `.34/.20/.26` pour éviter la double couche qui recomposait ~74 % de blanc. Ombre et rayon restent ceux de la card : `inset 0 1px 0 .95, inset 0 -1px 1px .4, inset 0 0 16px .12, 0 0 0 .5px rgba(23,43,36,.12), 0 10px 30px rgba(23,43,36,.14)`.
- **La bottom bar `.tb` reste la référence de navigation** : 48 px, padding 2 px, rayon 999 px, icônes 19 px, thumb `.62/.26`.
- **Mobile d'abord** : 393×852 et 375×667.
- **Ne pas casser** v12 → v18 : `npx vitest run tests/design/` reste vert (337 tests avant ajout).

## 6. Risques et résidus

- **`backdrop-filter` sur WebKit** : si la transparence ne se voit pas sur iOS, ajouter `-webkit-backdrop-filter` (déjà prévu) et vérifier que `.sw-wrap` n'a pas d'`opacity`/`filter` qui crée un nouveau contexte.
- **Drag et scroll** : la poignée a `touch-action: none` ; le corps garde son scroll. Si le pointer capture bloque le scroll, limiter le drag à `.grab` (déjà le cas).
- **Animation à l'ouverture** : le wrapper doit être en `data-det="card"` avant l'ajout de `.in`, sinon la feuille apparaît d'un coup. `animateSheetIn` force un reflow.
- **Fermeture et focus** : `finishClose()` restaure le focus sur l'ouvreur ; ne pas le faire deux fois (retirer l'ancien bloc de `setDet`).
- **Carte** : `flyToOuting` réutilise les coordonnées massif existantes ; si `OUTINGS` reçoit de vraies coordonnées, les préférer à `o.x/o.y`.
- **Résidu connu** : le menu pseudo reste un panneau de 180×54 sous la pilule (pas un morph pleine largeur) ; c'est volontaire pour ne pas masquer l'identité.
