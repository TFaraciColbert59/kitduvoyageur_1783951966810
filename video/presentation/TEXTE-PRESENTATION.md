# « D'une phrase, un carnet » — vidéo de présentation de l'app LKDV (texte v3)

Voix off grave, lente, cinématographique. Tutoiement. Une idée par ligne. « / » = respiration, « (silence) » = 1 à 2 s.
Deux fois, la voix de guidage de l'app parle seule. Un fil laiton (le tracé) passe d'écran en écran et relie toutes les pages.
Écrans = vision cible de l'app (carton « Vision produit — certaines fonctions à venir » si diffusion publicitaire).
Durée de la version longue : environ 5 min 20. Coupe réseaux de 60 s en bas de page.
Texte relu par un critique indépendant (couverture, récit, rythme, risques) puis réécrit.

## 0. OUVERTURE À FROID (0:00–0:20)
ÉCRAN : noir, vent, souffle. Le cockpit s'allume dans la nuit : tracé laiton, 2 516 m, frontale.
APP : « Dans deux cents mètres, à gauche. »
VOIX : Cinq heures douze. / Deux mille cinq cents mètres. / (silence) / Tu n'as jamais été aussi haut. / (silence) / Il y a six mois… / tu réapprenais à marcher.
ÉCRAN : coupe au noir. LE KIT DU VOYAGEUR.

## I. SE RELEVER — Compte (0:20–0:50)
ÉCRAN : mode rééducation, séries de renforcement cochées ; montre et capteur cardio connectés (Live Sync) ; activités, charge d'entraînement, Progression, Défis & Trophées ; heatmap mondiale puis zoom sur la zone de confidentialité autour du domicile (un cercle vide).
VOIX : Une séance. Puis une autre. / Le genou se souvient. Toi aussi. / Puis la montre reprend du service. / Le cœur. Le souffle. Le dénivelé. / Ta charge monte, doucement. / Un premier record. Un premier défi. / Un soir, tes chemins rejoignent ceux des autres. / Ta maison, elle, reste un blanc sur la carte.

## II. RÊVER — Explorer, Lieux, Communauté, Carnets (0:50–1:25)
ÉCRAN : globe Explorer (Islande, Népal, Patagonie, Alpes) ; calques (dangers signalés, feux et zones brûlées, repères) ; refuges et bivouacs, un lieu sensible flouté (« emplacement protégé ») ; fil Communauté, reels, stories, un club ; le carnet d'une voyageuse sur le Tour du Mont-Blanc : moments, photos posées sur le tracé, note vocale ; bouton « Préparer ce voyage ».
VOIX : Alors l'envie revient. / Le globe tourne sous tes doigts. / Un pays. Une vallée. Un refuge. / Ici, un bivouac. / Là, un danger signalé hier. / La carte est vivante. / (silence) / Et puis un carnet. / Celui d'une inconnue. / Ses photos, posées sur le tracé. / Sa voix, au col. / Un bouton : Préparer ce voyage.

## III. UNE PHRASE — Compas : Où, Résa, Verdict (1:25–2:20)
ÉCRAN : le carnet devient une phrase dans le Compas ; on tape « … en juillet » ; préparation visible ; Où : itinéraire sur de vrais lieux, nuits refuge et bivouac, carte ; météo heure par heure, alertes officielles ; Résa : Randos, Activités, Nuits, Vols, Trajets, Extras (assurance, eSIM), mention « liens partenaires » ; le budget se remplit ; Verdict.
VOIX : Le carnet devient une phrase. / Tu ajoutes deux mots : en juillet. / (silence) / Le Compas lit la carte. / De vrais sentiers. De vrais refuges. / Chaque étape, vérifiée sur la carte. / La météo, heure par heure. / Les alertes officielles, en clair. / Le train. La première nuit. L'assurance. / Chaque réservation rejoint ton budget. / Puis le verdict. / Pas une promesse. Une réponse. / Prêt… / (silence) / ou pas encore.

## IV. ENSEMBLE — Compas « Nous », Clubs, Sorties, Messagerie, Hub Groupe et Budget (2:20–2:55)
ÉCRAN : Compas « Nous » : un seul visage ; page club, départ la même semaine, « Je participe » ; annuaire des voyageurs ; Hub : Invitations, Groupe ; messagerie (photo, pièce jointe) ; « qui porte quoi » : la barre de poids se répartit ; Budget : qui doit quoi.
VOIX : Nous ? / Pour l'instant, toi seul. / (silence) / Pas longtemps. / Un club part la même semaine. / Tu réponds : Je participe. / Le groupe se forme. / Les messages se croisent. / La tente, le réchaud, la corde : / chacun voit ce qu'il porte. / Et qui doit quoi, à qui.

## V. S'ÉQUIPER — Compas « Kit », Hub Inventaire, Kit Studio, lignées, Boutique (2:55–3:40)
ÉCRAN : Compas Kit : « au-dessus de 2 400 m : crampons légers » ; Hub Inventaire (possédé / manquant), Alertes d'usure (kilomètres des chaussures) ; bandeau « Expédition active » sur l'accueil et la boutique ; Kit Studio : corps de sac réel, changement de coloris (pas d'objets en 3D) ; fiche de lignée : kit souche, « éprouvé », « gardé par 8 voyageurs sur 10 » ; Disponibilité : « Je prête » ; location, occasion, boutique, panier.
VOIX : Reste le sac. / Au-dessus de deux mille quatre cents mètres, / ton sac change. / Ton inventaire répond : / ceci, tu l'as. Ceci, il te manque. / Tes chaussures comptent leurs kilomètres. / Où que tu ailles, ton voyage te suit. / Dans le Kit Studio, ton sac prend forme. / Ce kit a une lignée. / Éprouvé sur le terrain. / Gardé par huit voyageurs sur dix. / La tente, Léa te la prête. / Le reste se loue, / se trouve d'occasion… / ou s'achète. Au bon endroit.

## VI. PARTIR — Hub Départ, Documents, Sécurité, suivi en direct (3:40–4:00)
ÉCRAN : Hub Départ : « À ne pas oublier » coché ; documents masqués (« visibles de toi seul ») ; cartes hors ligne téléchargées ; Sécurité : contacts ; suivi en direct : lien, durée, révocable.
VOIX : La veille, tout est prêt. / Les papiers. La liste. / Les cartes, même sans réseau. / Un lien, pour ceux qui t'attendent. / Toi seul décides jusqu'à quand.

## VII. SUR LE TERRAIN — Cockpit (4:00–4:45)
ÉCRAN : retour au plan d'ouverture, badge « hors ligne » ; guidage virage par virage, annonce vocale, boussole ; alerte au repère « source », alerte météo, alerte hors itinéraire ; montre au poignet ; centre de sécurité (112), bref ; lever de soleil au col, le groupe ; page /live sur un téléphone en ville (« dernière position il y a 3 min »).
VOIX : Cinq heures douze. / Te revoilà. / Plus de réseau. La carte, elle, est là. / Une voix, au creux de l'oreille. / APP : « Dans deux cents mètres, à gauche. » / La source est à vingt minutes. / Le ciel change. L'alerte arrive. / Tu t'écartes du tracé. / Il te le dit. Tu reviens. / Si tout bascule, / le 112 reste à un geste. / (silence, la musique s'ouvre) / Puis le col. / Le soleil, sur le glacier. / Ton genou tient. / (silence) / Le réseau revient. / Très loin, un téléphone s'allume. / Ta mère voit ton point passer le col.

## VIII. RACONTER — Hub Journal, Carnet (4:45–5:05)
ÉCRAN : Journal puis Carnet : moments, photo posée sur le tracé (Highlight), note vocale terrain, herbier (espèce identifiée), story ; couverture, « Publier » ; en vignette, export GPX / A4.
VOIX : Tu n'as presque rien écrit. / Pourtant tout est là. / Une photo, posée sur le tracé. / Ta voix, au col. / Une fleur que tu ne savais pas nommer. / Le carnet s'est écrit en marchant.

## IX. TRANSMETTRE — rapport du kit, lignée, part créateur, Passeport, Empreinte (5:05–5:35)
ÉCRAN : rapport terrain objet par objet (essentiel / jamais servi / manquait) ; la lignée s'étoffe ; part créateur en crédit boutique ; la tente rendue à Léa ; Passeport : tampon « massif » ; Empreinte : sceau, mention « Privée ».
VOIX : Au retour, ton sac parle. / Ceci a tout changé. / Ceci n'a jamais servi. / Ceci t'a manqué. / Ta réponse rejoint la lignée. / Les suivants partiront plus légers. / Quand quelqu'un s'équipe d'après ton kit, / une part te revient. / En crédit, pour ton prochain départ. / La tente de Léa rentre. Avec une histoire. / Ton empreinte gagne un massif. / Pas un classement. / La preuve que tu y étais. / Pour toi seul, tant que tu le choisis.
