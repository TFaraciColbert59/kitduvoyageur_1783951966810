# « Pas pour moi » — vidéo de présentation de l'app LKDV (texte v5, les Alpes)

Héros : un monsieur tout le monde qui n'a jamais osé partir. Ce qui le retient, ce sont ses excuses.
Procédé : chaque excuse s'écrit à l'écran (comme une pensée), une page de l'app y répond, puis le fil laiton la barre.
Le voyage : cinq jours dans les Alpes du Nord, trois activités — kayak sur le lac d'Annecy, via ferrata à Chamonix, randonnée jusqu'au refuge du Lac Blanc (2 352 m), face au Mont-Blanc.
Voix off grave, lente, cinématographique. Tutoiement. « / » = respiration, « (silence) » = 1 à 2 s. Deux fois, la voix de guidage de l'app parle seule.
Libellés à l'écran = libellés réels de l'app (inventaire video/film-lkdv/INVENTAIRE.md). Écrans = vision cible quand la fonction n'est pas finie.
Durée de la version longue : environ 5 min 30. Coupe réseaux de 60 s en bas de page.
v3 relue par un critique indépendant ; v4 : héros « monsieur tout le monde » (Tony) ; v5 : les Alpes, plusieurs activités, revérification des pages (Tony) ; v6 : les types de cartes, les filtres et les couches à venir (Tony).
