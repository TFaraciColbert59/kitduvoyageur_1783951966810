# « Pas pour moi » — vidéo de présentation de l'app LKDV (texte v4)

Héros : un monsieur tout le monde qui n'a jamais osé partir. Ce qui le retient, ce sont ses excuses.
Procédé : chaque excuse s'écrit à l'écran (typographie simple, comme une pensée), une page de l'app y répond, puis le fil laiton la barre.
Voix off grave, lente, cinématographique. Tutoiement. « / » = respiration, « (silence) » = 1 à 2 s.
Deux fois, la voix de guidage de l'app parle seule. Le fil laiton (le tracé) passe d'écran en écran et relie toutes les pages.
Écrans = vision cible de l'app (carton « Vision produit — certaines fonctions à venir » si diffusion publicitaire).
Lieu : le Tour du Mont-Blanc, en refuges. Durée de la version longue : environ 5 min 20. Coupe réseaux de 60 s en bas de page.
v3 relue par un critique indépendant ; v4 = changement de héros demandé par Tony (plus de blessure : quelqu'un qui n'a jamais osé).

## 0. OUVERTURE À FROID (0:00–0:20)
ÉCRAN : noir, vent, souffle. Le cockpit s'allume dans la nuit : tracé laiton, 2 516 m, frontale.
APP : « Dans deux cents mètres, à gauche. »
VOIX : Cinq heures douze. / Deux mille cinq cents mètres. / (silence) / Tu n'as jamais été aussi loin. / (silence) / Il y a six mois, / tu disais encore : / pas pour moi.
ÉCRAN : « Pas pour moi. » s'écrit, coupe au noir. LE KIT DU VOYAGEUR.

## I. « JE NE SUIS PAS SPORTIF » — Compte (0:20–0:50)
ÉCRAN : l'excuse s'écrit ; Compte : « Enregistrer une sortie » un dimanche (4 km près de chez lui), la montre synchronisée, puis 8 km, 12 km ; dénivelé qui grimpe ; Progression, premier Défi validé, trophée ; heatmap mondiale, puis zoom sur la zone de confidentialité autour du domicile (un cercle vide). Le fil laiton barre l'excuse.
VOIX : Alors tu as commencé petit. / Un dimanche. Quatre kilomètres. / Puis huit. Puis douze. / Ta montre a tout retenu. / Le souffle. Le dénivelé. / Un premier défi. / Tu ne l'aurais pas cru. / Un soir, tes chemins rejoignent ceux des autres. / Ta maison, elle, reste un blanc sur la carte.

## II. « JE NE SAURAIS PAS OÙ ALLER » — Explorer, Lieux, Communauté, Carnets (0:50–1:25)
ÉCRAN : l'excuse s'écrit ; globe Explorer (Islande, Népal, Patagonie, Alpes) ; calques (dangers signalés, repères) ; refuges et bivouacs, un lieu sensible flouté (« emplacement protégé ») ; fil Communauté, reels, stories, un club ; le carnet d'un voyageur sur le Tour du Mont-Blanc : moments, photos posées sur le tracé, note vocale ; bouton « Préparer ce voyage ». Le fil barre l'excuse.
VOIX : Le globe tourne sous tes doigts. / Un pays. Une vallée. Un refuge. / Ici, un bivouac. / Là, un danger signalé hier. / La carte est vivante. / (silence) / Et puis un carnet. / Celui d'un inconnu. / Ses photos, posées sur le tracé. / Sa voix, au col. / Un bouton : Préparer ce voyage.

## III. « C'EST TROP COMPLIQUÉ » — Compas : Où, Résa, Verdict (1:25–2:20)
ÉCRAN : l'excuse s'écrit ; le carnet devient une phrase dans le Compas, on tape « … en juillet » ; préparation visible ; Où : itinéraire sur de vrais lieux, nuits en refuge, carte ; météo heure par heure, alertes officielles ; Résa : Randos, Activités, Nuits, Vols, Trajets, Extras (assurance), mention « liens partenaires » ; le budget se remplit ; Verdict. Le fil barre l'excuse.
VOIX : Une phrase. / C'est tout ce qu'on te demande. / Tu ajoutes deux mots : en juillet. / (silence) / Le Compas lit la carte. / De vrais sentiers. De vrais refuges. / Chaque étape, vérifiée sur la carte. / La météo, heure par heure. / Les alertes officielles, en clair. / Le train. La première nuit. L'assurance. / Chaque réservation rejoint ton budget. / Puis le verdict. / Pas une promesse. Une réponse. / Prêt… / (silence) / ou pas encore.

## IV. « JE N'AI PERSONNE AVEC QUI PARTIR » — Compas « Nous », Clubs, Sorties, Messagerie, Hub Groupe et Budget (2:20–2:55)
ÉCRAN : l'excuse s'écrit ; Compas « Nous » : un seul visage ; page club, départ la même semaine, « Je participe » ; annuaire des voyageurs ; Hub : Invitations, Groupe ; messagerie (photo, pièce jointe) ; « qui porte quoi » : la barre de poids se répartit ; Budget : qui doit quoi. Le fil barre l'excuse.
VOIX : Nous ? / Pour l'instant, toi seul. / (silence) / Pas longtemps. / Un club part la même semaine. / Tu réponds : Je participe. / Des inconnus, puis des prénoms. / Les messages se croisent. / Le réchaud, la trousse, la carte : / chacun voit ce qu'il porte. / Et qui doit quoi, à qui.

## V. « JE N'AI PAS LE MATÉRIEL » — Compas « Kit », Hub Inventaire, Kit Studio, lignées, Boutique (2:55–3:40)
ÉCRAN : l'excuse s'écrit ; Compas Kit : « au-dessus de 2 400 m : une couche chaude » ; Hub Inventaire (possédé / manquant), Alertes d'usure (kilomètres des chaussures) ; bandeau « Expédition active » sur l'accueil et la boutique ; Kit Studio : corps de sac réel, changement de coloris (pas d'objets en 3D) ; fiche de lignée : kit souche, « éprouvé », « gardé par 8 voyageurs sur 10 » ; Disponibilité : « Je prête » ; location, occasion, boutique, panier. Le fil barre l'excuse.
VOIX : Reste le sac. / Tu pensais devoir tout acheter. / Ton inventaire répond : / ceci, tu l'as déjà. Ceci, il te manque. / Au-dessus de deux mille quatre cents mètres, / une couche de plus. / Où que tu ailles, ton voyage te suit. / Dans le Kit Studio, ton sac prend forme. / Ce kit a une lignée. / Éprouvé sur le terrain. / Gardé par huit voyageurs sur dix. / Les bâtons, Léa te les prête. / Le reste se loue, / se trouve d'occasion… / ou s'achète. Au bon endroit.

## VI. « ET SI J'OUBLIE QUELQUE CHOSE ? » — Hub Départ, Documents, Sécurité, suivi en direct (3:40–4:00)
ÉCRAN : l'excuse s'écrit ; Hub Départ : « À ne pas oublier » coché ; documents masqués (« visibles de toi seul ») ; cartes hors ligne téléchargées ; Sécurité : contacts ; suivi en direct : lien, durée, révocable. Le fil barre l'excuse.
VOIX : La veille, tout est prêt. / Les papiers. La liste. / Les cartes, même sans réseau. / Un lien, pour ceux qui t'attendent. / Toi seul décides jusqu'à quand.

## VII. « ET SI JE ME PERDS ? » — Cockpit (4:00–4:45)
ÉCRAN : l'excuse s'écrit, puis retour au plan d'ouverture, badge « hors ligne » ; guidage virage par virage, annonce vocale, boussole ; alerte au repère « source », alerte météo, alerte hors itinéraire ; montre au poignet ; centre de sécurité (112), bref ; lever de soleil au col, le groupe ; page /live sur un téléphone en ville (« dernière position il y a 3 min »). Le fil barre la dernière excuse.
VOIX : Cinq heures douze. / Te revoilà. / Plus de réseau. La carte, elle, est là. / Une voix, au creux de l'oreille. / APP : « Dans deux cents mètres, à gauche. » / La source est à vingt minutes. / Le ciel change. L'alerte arrive. / Tu t'écartes du tracé. / Il te le dit. Tu reviens. / Si tout bascule, / le 112 reste à un geste. / (silence, la musique s'ouvre) / Puis le col. / Le soleil, sur le glacier. / Toi. Ici. / (silence) / Le réseau revient. / Très loin, un téléphone s'allume. / Ta mère voit ton point passer le col.

## VIII. RACONTER — Hub Journal, Carnet (4:45–5:05)
ÉCRAN : Journal puis Carnet : moments, photo posée sur le tracé (Highlight), note vocale terrain, herbier (espèce identifiée), story ; couverture, « Publier » ; en vignette, export GPX / A4.
VOIX : Tu n'as presque rien écrit. / Pourtant tout est là. / Une photo, posée sur le tracé. / Ta voix, au col. / Une fleur que tu ne savais pas nommer. / Le carnet s'est écrit en marchant.

## IX. TRANSMETTRE — rapport du kit, lignée, part créateur, Passeport, Empreinte (5:05–5:35)
ÉCRAN : rapport terrain objet par objet (essentiel / jamais servi / manquait) ; la lignée s'étoffe ; part créateur en crédit boutique ; les bâtons rendus à Léa ; Passeport : premier tampon ; Empreinte : sceau, mention « Privée ».
VOIX : Au retour, ton sac parle. / Ceci a tout changé. / Ceci n'a jamais servi. / Ceci t'a manqué. / Ta réponse rejoint la lignée. / Les suivants partiront plus légers. / Quand quelqu'un s'équipe d'après ton kit, / une part te revient. / En crédit, pour ton prochain départ. / Les bâtons de Léa rentrent. Avec une histoire. / Ton passeport, son premier tampon. / Pas un classement. / La preuve que tu y étais. / Pour toi seul, tant que tu le choisis.

ÉCRAN : un autre téléphone, un autre soir : « Pas pour moi. » s'écrit à l'écran de quelqu'un d'autre ; il ouvre ton carnet, un doigt sur « Préparer ce voyage » ; le fil laiton barre l'excuse, relie toutes les pages vues (carnet → Compas → Hub → sac → cockpit → carnet) et se referme en logo ; carton : Explorer · Compas · Hub · Kit Studio · Communauté · Terrain · Carnets — en petit : Espace Pro · Développeurs · Manifeste.
VOIX : Un soir, quelque part, / quelqu'un qui n'a jamais osé / ouvre ton carnet. / Il touche : Préparer ce voyage. / (silence) / D'une phrase, un carnet. / D'un carnet, une phrase. / Le Kit du Voyageur.
