DIRECTION ARTISTIQUE (non négociable) :
1. FULL LIQUID GLASS. Tout ce qui est interface est en verre : cartes, tuiles,
   cellules, boutons, pilules, chips, badges, champs, segmented, toggles, tab bar,
   barres secondaires, TopBar, sheets, modales, alertes, toasts, menus, popovers,
   contrôles de carte, HUD, squelettes, états vides.
2. VERRE SUR VERRE AUTORISÉ ET VOULU. Les couches s'empilent (carte de verre →
   cellule de verre → pilule de verre). La profondeur vient de l'empilement.
3. AUCUNE COULEUR PRIMAIRE. Pas de vert menthe, pas d'accent de marque, pas de CTA
   coloré. L'interface est monochrome : verre neutre + encre (light) ou lumière
   (dark). La hiérarchie passe par la densité du verre, la luminosité, l'épaisseur
   du bord, le reflet, la graisse du texte et la taille.
   Seule couleur tolérée : les statuts (danger, warning, success), et seulement
   comme légère teinte de verre ou sur une icône, jamais comme identité ni comme
   fond plein. Les contenus (photos, cartes, graphiques) gardent leurs couleurs.
4. LISIBILITÉ AVANT TOUT. Le verre ne justifie jamais un texte illisible :
   ≥ 4.5:1 pour le texte, mesuré sur le pire pixel derrière lui, en light et en dark.

### 7.2 La matière : 5 niveaux de verre
Tous pilotés par --glass-intensity (0 = clair … 1 = teinté), avec un réglage
utilisateur dans /compte (localStorage, pas en base), plus des variantes light/dark.
Teinte neutre uniquement : blanc en light, graphite neutre en dark, jamais de vert.

G0 · Fond : photo + scrim global adaptatif (dégradé + voile), fixed, 100dvh, qui
     couvre tout le scroll. Plus aucune bande vert uni.
G1 · Verre de base (« regular ») : TopBar, tab bar, barres secondaires, cartes de
     premier niveau, sheets, modales. VRAI backdrop-filter.
G2 · Verre intérieur : cellules, tuiles, lignes de liste, champs, chips et pilules
     posés dans un G1. Construit SANS nouveau backdrop-filter (voir 7.3) : couche de
     lumière + bord + reflet. Visuellement, du verre sur du verre.
G3 · Verre prominent (remplace le CTA coloré) : action principale. Light = verre
     encre dense (≈ 82–88 %) + texte blanc ; dark = verre lumineux dense (≈ 86–92 %)
     + texte encre. Reflet plus fort, bord plus net, légère ombre portée.
     Un seul G3 par écran.
GC · Verre clair (« clear ») : contrôles posés sur un média (carte, photo, lecteur) :
     boutons de carte, HUD, actions sur hero. Verre plus transparent + voile
     d'assombrissement local sous l'icône pour garantir ≥ 3:1.

Exemple de base (à adapter et tester) :
~~~css
:root {
  --glass-intensity: 0.5;
  --glass-tint: 255 255 255;                         /* light */
  --glass-ink: 18 18 20;
  --glass-blur: calc(20px + 12px * var(--glass-intensity));
  --glass-sat: 180%;
  --g1-bg: rgb(var(--glass-tint) / calc(0.42 + 0.34 * var(--glass-intensity)));
  --g2-bg: rgb(var(--glass-tint) / calc(0.30 + 0.25 * var(--glass-intensity)));
  --glass-rim: 0 0 0 0.5px rgb(0 0 0 / .22);          /* bord assombri iOS 27 */
  --glass-rim-inner: inset 0 0 0 0.5px rgb(255 255 255 / .45);
  --glass-highlight: inset 0 1px 0 rgb(255 255 255 / .55);
  --glass-shadow: 0 10px 36px rgb(0 0 0 / .16);
}
[data-theme="dark"] {
  --glass-tint: 34 34 38;
  --g1-bg: rgb(var(--glass-tint) / calc(0.50 + 0.32 * var(--glass-intensity)));
  --g2-bg: rgb(255 255 255 / calc(0.07 + 0.07 * var(--glass-intensity)));
  --glass-rim: 0 0 0 0.5px rgb(0 0 0 / .55);
  --glass-highlight: inset 0 1px 0 rgb(255 255 255 / .18);
}
.g1 {
  background: var(--g1-bg);
  backdrop-filter: blur(var(--glass-blur)) saturate(var(--glass-sat));
  -webkit-backdrop-filter: blur(var(--glass-blur)) saturate(var(--glass-sat));
  box-shadow: var(--glass-rim), var(--glass-rim-inner), var(--glass-highlight), var(--glass-shadow);
}
.g2 { background: var(--g2-bg); box-shadow: var(--glass-rim), var(--glass-highlight); }
/* reflet spéculaire : ::before avec dégradé linéaire + masque sur le bord (padding-box/border-box) */
@supports not ((backdrop-filter: blur(1px)) or (-webkit-backdrop-filter: blur(1px))) {
  .g1 { background: rgb(var(--glass-tint) / .94); }
}
@media (prefers-reduced-transparency: reduce), (prefers-contrast: more) {
  .g1, .g2, .g3, .gc { backdrop-filter: none; -webkit-backdrop-filter: none; }
  .g1 { background: rgb(var(--glass-tint) / 1); box-shadow: 0 0 0 1px rgb(var(--glass-ink) / .45); }
  .g2 { background: rgb(var(--glass-ink) / .08); }
}
~~~
Chaque niveau doit se distinguer du niveau inférieur (luminosité ΔL ≥ 4 en OKLab,
bord et reflet visibles). Documente-le avec des planches dans audit/GLASS.md.

### 7.3 Verre sur verre : règles techniques
- Un élément qui a un backdrop-filter crée une « backdrop root » : un backdrop-filter
  imbriqué ne floute que le contenu de son parent, pas la photo. Donc : G1 porte le
  vrai flou, G2 et G3 simulent la matière (couche de lumière, bord, reflet, ombre
  interne). Un backdrop-filter imbriqué n'est permis que s'il apporte un gain
  visible mesuré, et il est documenté.
- Évite les ancêtres qui cassent le flou (opacity < 1, filter, mask, will-change:
  filter, overflow et transform mal placés) : audite chaque G1.
- Formes proches qui fusionnent (équivalent GlassEffectContainer) : groupes de pilules
  (segmented, barres d'actions, contrôles de carte) sur UN seul G1 capsule avec
  séparateurs, indicateur G2 qui glisse.
- Réfraction SVG (feDisplacementMap) en amélioration progressive, uniquement sous
  Chromium, sur la tab bar et 1 à 2 éléments hero ; désactivée sous
  reduced-motion/transparency, sur les appareils lents et sous Safari.
- Budget GPU : ≤ 8 éléments avec un vrai backdrop-filter visibles à la fois sur mobile ;
  listes longues avec content-visibility: auto ; pas de backdrop-filter animé
  (anime l'opacité d'un calque déjà flouté). Mesure en traces : 60 fps au scroll.

### 7.4 Lisibilité sur le verre (obligatoire)
- Couleurs de texte « vibrantes » monochromes : label, secondaryLabel, tertiaryLabel,
  quaternary, en light et en dark, calibrées pour ≥ 4.5 / 4.5 / 3:1 AU PIRE CAS sur
  G1 et G2, aux trois intensités.
- Si une valeur échoue, remonte l'opacité minimale du verre concerné ; ne baisse
  jamais le seuil.
- Texte long (descriptions, avis, articles) : G1 à intensité forcée ≥ 0.7 ou calque
  de lisibilité interne ; jamais sur GC.
- Aucun texte directement sur la photo, sauf les titres hero sur un scrim local.
- Statuts : icône + texte + teinte légère du verre (≤ 12 %) ; le texte reste
  label/secondaryLabel.
- tests/design/contrast.spec.ts : (a) couples de tokens sur fonds simulés (photo la
  plus claire et la plus sombre de l'app, floutées) ; (b) mesure pixel sur les
  captures de 20 écrans clés.

### 7.5 Typographie
Pile SF (-apple-system, "SF Pro Text", "SF Pro Display", system-ui…). Justifie
Manrope, Georgia et Mono, ou supprime-les ; mono réservée au GPS et aux codes.
Boutons 17 semibold (15 en compact). Eyebrows 13 semibold, pas de mono en capitales.
Titres en label (encre ou blanc), jamais en couleur.

### 7.6 Espacement, couches, motion
- Échelle 4/8 ; marges d'écran 16/20 ; 24–32 entre sections.
- Échelle z-index unique : contenu < sticky < barre secondaire < tab bar < HUD < sheet
  < toast < alerte (la carte 400/1000 comprise).
- --nav-height unique ; --tabbar-h, --subbar-h, --sticky-cta-h, --safe-bottom →
  --content-pb calculé.
- Motion : ressorts (response 0.35–0.5, amortissement 0.8–0.9), press-scale 0.97 +
  éclaircissement du verre à l'appui (le reflet « s'allume »), morphing de la tab bar
  entre ses tailles, sélection du segmented par déplacement fluide du G2, bande
  uniforme en haut quand le contenu passe sous les barres.

### 7.7 Primitives (toutes en verre)
GlassSurface (G1/G2/G3/GC, prop level), LkvButton (prominent G3, glass G2, plain ·
50/44/36 · capsule), IconButton (cercle 44), Pill/Chip, SegmentedControl, TextField,
