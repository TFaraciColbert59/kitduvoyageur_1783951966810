# Mobile UX

LKDV should feel like a polished mobile application, not a compressed desktop website.

Prioritize:
- touch interaction
- smooth transitions
- responsive layouts
- fast feedback
- readable typography
- accessible controls
- low cognitive load

## Interaction

Interactive elements should:
- provide immediate visual feedback
- have appropriate touch targets
- avoid accidental activation
- have clear active states
- preserve predictable navigation

## Loading

Use appropriate:
- skeletons
- optimistic updates
- loading indicators
- empty states
- error states

Never leave users staring at a blank screen.

## Motion

Use animation intentionally.

Prefer:
- short transitions
- subtle micro-interactions
- page transitions
- meaningful state changes

Avoid:
- excessive animation
- animation that blocks interaction
- unnecessary continuous animations

## Responsive

Test:
- small mobile
- large mobile
- tablet
- desktop

Mobile should be treated as a primary experience.

## Accessibility

Consider:
- keyboard navigation
- focus states
- semantic HTML
- contrast
- labels
- ARIA where appropriate
- reduced motion
