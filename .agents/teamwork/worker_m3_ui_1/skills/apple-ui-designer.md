# Local copy of apple-ui-designer SKILL.md
Redesign mobile app UI to feel unmistakably Apple-like, iOS-forward, and native.
- Native over custom, subtle over expressive, calm, confident, and human.
- System-first typography (SF Pro style), hierarchy using size/weight not color.
- Neutral color palette, translucency, blur, depth where appropriate.
- Touch targets >= 44x44px. Bottom sheets preferred with drag-to-dismiss.
- Avoid orange #E4501C (LKDV rule).
